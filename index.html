Build 2D games
in the browser.

Realot Studio is a browser-based 2D game engine with a visual editor, JavaScript scripting, Rapier2D physics, navigation, lighting and web export.

Build your first game Browse the docs
js
function onStart() {
  this.speed = 220;
}

function onUpdate(dt) {
  if (input.keyDown("ArrowRight")) {
    this.x += this.speed * dt;
  }
  if (input.keyPressed("Space")) {
    this.rigidbody.addImpulse(0, -350);
  }
}

Everything the engine does, documented

Pages are written from the shipped source: field names, defaults, script members and menu paths are checked, not guessed.

Editor, end to end

Hierarchy, Inspector, viewport tools, prefabs, physics layers and nav areas — with exact menu paths and shortcuts.

JavaScript scripting

Lifecycle hooks, this context, globals, timers, messaging and typed errors.

Rapier2D physics

Dynamic, kinematic and static bodies, 16-layer filtering, joints and one-way platforms.

Grid navigation

NavWorld2D bake & paint, 16 areas with costs, NavAgent2D steering and avoidance.

2D lighting

Six light types, shadow casters and quad or raymarched shadows.

Tween & time control

tween() with 33 easings, cancelTween(), and time.scale for slow motion or freeze.

Ship your game

Export HTML5 or PWA in the browser, or build a debug-signed Android APK through the configured service.
