Standalone game package

The browser builds a standalone ZIP with index.html at its root, a game entry script, runtime files and referenced assets. It does not include the editor or Hub. The Android build flow consumes this same standalone export package rather than reconstructing a game from editor-only project data.

Run a web export

Serve the exported folder through HTTP(S) or upload it to a static host. Do not double-click index.html from the file system: browser module and asset requests can fail under file://.
